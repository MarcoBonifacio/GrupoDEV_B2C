El sistema permite centralizar el control de stock, administrar carritos de compra de forma interactiva y emitir comprobantes dinámicos en PDF adaptados a las normativas fiscales vigentes.  Desarrollado mediante un enfoque ágil, el software cuenta con una estructura modular que garantiza una óptima separación de responsabilidades y escalabilidad empresarial.  🚀 Características Clave🛒 Experiencia de Usuario (UI/UX)Catálogo Unificado: Filtro y visualización dinámica de 63 modelos distribuidos en 6 marcas líderes: Capsa, Solite, Varta, Ultrabat, Etna y Enerjet.  Búsqueda Avanzada: Motor predictivo por nombre, modelo de batería y especificaciones de voltaje.  Persistencia Local: Carrito de compras con sincronización en tiempo real mediante localStorage para evitar la pérdida de datos del cliente.  Diseño Adaptativo & Dark Mode: Interfaz Mobile-First (Mobile, Tablet, Desktop) con soporte nativo para tema oscuro a través de variables CSS centralizadas.  💳 Pasarela de Pagos & Facturación DinámicaMedios de Pago Populares: Integración visual interactiva para pagos con Yape, Plin y Tarjetas de Crédito/Débito.
